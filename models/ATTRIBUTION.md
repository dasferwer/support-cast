# Происхождение данных и модели

Демонстрационная история и обученные коэффициенты получены из набора
FiveThirtyEight **Sandy-related NYC 311 calls by day**.
Исходная публикация: https://github.com/fivethirtyeight/data/tree/e0c8091a3ba3be547b15a704b1ceb25b211e676b/sandy-311-calls

Данные распространяются по CC BY 4.0; полный текст — DATA-LICENSE.txt.
Из исходной таблицы использована сумма звонков за день. История обрезана
по 2014-12-31, на её основе построены признаки и обучены Ridge-модели.
Проект и изменения: SupportCast, сентябрь 2026. Автор исходных данных
не подтверждал качество модели и не связан с этим проектом.
Код проекта распространяется по MIT; эта лицензия не заменяет лицензию данных.
