# Модель sandy-v1

## Данные и происхождение

[FiveThirtyEight: Sandy 311 calls](https://github.com/fivethirtyeight/data/tree/e0c8091a3ba3be547b15a704b1ceb25b211e676b/sandy-311-calls), зафиксированный commit `e0c8091a3ba3be547b15a704b1ceb25b211e676b`. В `data/calls.csv` 1783 дневные строки за 22.10.2012–08.09.2017. Используется суммарное число звонков за день. Это обращения, связанные с Sandy, а не все звонки в NYC 311. Таблица не содержит имён или контактов заявителей.

`data/source.json` хранит SHA-256 исходного CSV, описания и лицензии. Скрипт обучения проверяет хеши. Исходная публикация и данные распространяются по CC BY 4.0; копия лицензии и указание преобразований включены также в каталог модели, который попадает в Docker runtime.

## Протокол оценки

Сначала был исследован конец ряда в 2017 году: там осталось очень мало звонков. После этого добавлен отдельный исторический срез до 31.12.2014. Выбор этого периода сделан после просмотра разреженности данных, поэтому это исследовательская оценка, а не заранее зарегистрированный benchmark. Результаты 2017 года сохранены в `sparse_tail_periods`; они не скрыты и используют тот же alpha.

Для среза 2014 года валидация — восемь недель с 11.09.2014, тест — восемь следующих недель с 06.11.2014. Каждую неделю модель заново обучается только на доступном прошлом и выдаёт сразу семь дневных прогнозов. В расчёт признаков не попадают будущие значения. Подобный порядок нужен для временных рядов; случайное перемешивание делает оценку слишком оптимистичной ([пример scikit-learn](https://scikit-learn.org/stable/auto_examples/applications/plot_time_series_lagged_features.html)).

Сравниваются недельный повтор и Ridge с alpha 1, 10, 100. Alpha 100 и выбор Ridge получены по MAE валидации. На тесте параметры не выбираются. Итоговый serving-файл переобучен на всём историческом срезе; опубликованные тестовые прогнозы получены отдельными моделями, обученными на каждой своей дате.

| Алгоритм | MAE, обращений | WAPE | Покрытие интервала на тесте |
|---|---:|---:|---:|
| Тот же день прошлой недели | 1,5893 | 108,54% | 100% |
| Ridge | 1,0784 | 73,65% | 96,43% |

MAE — средняя абсолютная ошибка. WAPE — сумма абсолютных ошибок, делённая на сумму фактических значений. Высокая WAPE указывает, что эти данные пока плохо подходят для точного оперативного планирования. Полный отчёт содержит отдельные прогнозы и факты по всем восьми неделям, а тест повторно вычисляет итоговые метрики.

## Признаки и пропуски

Для каждого из семи горизонтов обучена своя модель. Признаки: 28 лагов, средние за 7 и 28 дней, день недели целевой даты, годовой синус и косинус, федеральный праздник США и доля пропусков. Календарь праздников записан в артефакте на 2012–2032 годы. За его пределами праздник не распознаётся; календарь другой страны требуется заменить и проверить отдельно.

Пропущенное значение заполняется медианой предыдущих четырёх совпадающих дней недели; запасной вариант — предыдущие 28 дней. Заполнение причинное, исходные `null` остаются в диагностике. Аномалия отмечается по медиане и MAD прошлого окна. Исходные всплески сохраняются, а величины лагов ограничиваются перед логарифмированием. Модель не предсказывает неизвестный будущий кризис по одному календарю.

Интервал строится по 90-му процентилю абсолютной ошибки валидации отдельно для горизонта. На каждый горизонт всего восемь ошибок. Это эмпирический диапазон, без гарантии 90% покрытия и без предположения, что реальная нагрузка симметрична.

## Повторное обучение

```bash
uv sync --extra dev --frozen
uv run python scripts/train.py --version sandy-reproduction
```

Новая версия записывается отдельно; существующий каталог не перезаписывается. Результат — числовые коэффициенты и параметры нормализации в JSON, `evaluation.json` и демонстрационная история. Для смены serving-версии нужно обновить `VERSION` в `service.py`, сохранить артефакт и пересобрать контейнеры. Принятые задания привязаны к прежнему хешу: до замены надо завершить очередь старой версии либо оставить её доступной. Автоматического registry, мониторинга drift и фонового переобучения нет; автоматически обновляется прогноз после приёма наблюдений.
