# Независимые ряды и интервалы

Два связанных, но разных ряда UCI Bike Sharing: дневные аренды случайных и зарегистрированных пользователей, 731 день (2011–2012). Это проверка иного процесса/масштаба, а не подтверждение качества обращений в другую организацию. Источник и CC BY 4.0 — [UCI](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset), автор Hadi Fanaee-T; DOI 10.24432/C5W894. Исходный CSV, README и лицензия сохранены в `data/independent`, контрольные суммы — `source.json`. Персональных данных нет.

Последние 56 дней (06.11–31.12.2012), восемь неперекрывающихся недель, горизонты 1–7. На горизонт только восемь наблюдений; два ряда не статистически независимы. JSON содержит все факты/прогнозы, MAE, WAPE, фактическое coverage по включительным границам и ширину интервалов по каждому горизонту. При нулевом знаменателе WAPE = null.

Первый профиль — неизменный `sandy-v1`, включая радиусы. Он обучен на Sandy до 2014 года: это ретроспективная проверка переноса между источниками, **не backtest исторического развёртывания в 2012 году**. Данные Bike Sharing не участвовали в Sandy-обучении; будущее проверяемого ряда не попадает в историю.

Второй профиль — отдельное evaluation-only обучение на префиксе Bike Sharing. Alpha заранее взят из существующего Sandy artifact; подбора по внешним labels нет. Калибровка — восемь rolling origins в 56 днях перед test, каждый fit использует только свой прошлый префикс. Радиусы — 90%-квантиль абсолютных ошибок с `method=higher` отдельно по горизонту. Финальный fit ограничен 05.11.2012; модель и радиусы не обновляются внутри test. Оба алгоритма показаны, победитель по test не выбирается. Production artifact и его версия не изменены.

Stress фиксируется индексами: missing удаляет каждый пятый день только истории, сохраняя края; level_shift удваивает факты с начала test (история получает новый уровень только после наблюдения); outliers умножает на десять origin−2 и origin−9 только в истории. Истинные будущие значения для missing/outliers не изменяются. Пропуски заполняет существующий причинный `regularize`; future labels не участвуют в заполнении, настройке или калибровке.

Покрытие при прямом переносе почти нулевое: Sandy-радиусы около 7–11 обращений несоразмерны сотням/тысячам аренд. Калибровка на префиксе улучшает масштаб интервалов, но новый уровень/выбросы остаются отдельным риском. Номинальные 90% не гарантированы; дневной прогноз и staff heuristic не доказывают SLA. Нельзя использовать Sandy-радиусы на новом потоке без собственной предшествующей калибровки. Данный пакет измеряет границы, а не заменяет production модель.

Воспроизведение: `uv run python scripts/evaluate_independent.py --output /tmp/supportcast-evaluation.json`. Сравните JSON с `docs/independent-evaluation.json`; сеть не нужна. Тесты проверяют метрики, знаменатели, число samples по горизонту, неизменность artifact, checksum и то, что изменение всех test labels не меняет обучение/радиусы. Версии входа API и snapshot остаются под существующими интеграционными тестами.
