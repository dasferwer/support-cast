## Что проверяли

Проверены повторная конкурентная загрузка, конфликт версий, изоляция владельцев, откат некорректной пачки, неизменность принятого снимка и восстановление worker. После SIGKILL тот же job завершился со второй попытки. Запоздалое поколение исполнителя не смогло записать результат.

ML-тесты проверяют причинное заполнение пропусков, дату последней обучающей цели, контроль хеша модели, недельный baseline и повторный расчёт опубликованных метрик восьми тестовых недель. Отдельный повтор полного обучения с `--version sandy-reproduction` дал одинаковые числовые параметры, весь отчёт оценки и demo-историю (за исключением имени версии в модели и отчёте).

Повторное обучение проверялось на этом же окружении и зафиксированных зависимостях. Побитовое совпадение между разными BLAS, платформами и версиями библиотек не заявляется. Ограничения данных и качества — в [карточке модели](model-card.md).

В runtime также отсутствуют pandas и scikit-learn: числовой прогноз выполняет NumPy. SHA-256 сохранённой OpenAPI-схемы указан в JSON-отчёте.

## Повторить

```bash
make check
make test
make up
make smoke
make recovery
docker compose exec -T api python scripts/seed.py
docker compose exec -T api python scripts/seed.py
```

Тестовая база отделена от пользовательской и остановлена после проверки. Рабочие контейнеры оставлены запущенными. В репозитории есть GitHub Actions workflow для этих же основных проверок; удалённый CI пока не запускался, поскольку этот репозиторий ещё не опубликован.
